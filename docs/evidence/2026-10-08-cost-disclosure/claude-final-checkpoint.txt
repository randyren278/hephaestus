### Remaining must-fix defects
1. **The support-triage daemon command will fail at `arena evaluate` (new finding, blocks the pilot).**
   - `examples/support-triage/README.md:41-45` passes `--evaluator-executable "$HEPH_BIN/hephaestus-reference-evaluator"`, where `HEPH_BIN` is the directory holding `hephaestus` on your PATH.
   - Both installers put **symlinks** there (`scripts/install.sh:199`, `scripts/package/install.sh:77`).
   - The daemon stores that path unchanged (`server.rs:1051`). The evaluator check then rejects any path that is itself a symlink (`isolated_evaluator.rs:209-217`), and the error surfaces only as `Internal` (`run_exec.rs:1237`).
   - The evaluator is opened at admission (`run_exec.rs:432`), before any trial runs, so no provider quota is spent. But the documented pilot cannot reach Selection.
   - The package acceptance run didn't catch this because it uses `share/hephaestus/current/bin/...`, where the last path component is a regular file (`package_macos_acceptance.sh:51`). The support-triage preparation run stopped before `arena evaluate`.
   - **Fix:** point the docs at the real file (for a package, `~/.local/share/hephaestus/current/bin/hephaestus-reference-evaluator`; for a source install, `target/release/...`), or resolve the path once when the daemon starts. Then add a test that exercises this exact command.
2. **`file_event_store.rs:222-238` (already known, unchanged):** the length check counts bytes but the decoder walks characters, so a trailing non-ASCII character can be silently dropped. This is correctly tracked as open at `PRODUCT_READINESS.md:309-312`. This syntax-only checkpoint does not complete trust readiness.
