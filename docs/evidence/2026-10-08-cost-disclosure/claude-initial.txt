I found no misleading commercial promises. The cost wording now avoids claiming a measured cost, and it never says every zero is unknown. One blocker remains: the cost disclosure overflows the TUI layout on small terminals. The new engineer is also missing some setup steps.

## Blockers

**1. Cost disclosure overflows the TUI on small terminals.**
- `ui.tsx:837` sets `panelHeight = max(3, rows-10)` in compact mode. At rows < 13 that gives `height = 1`.
- `windowedGroups(..., height - 2)` then rounds up to 1 row (`evidence.ts:62`). The panel draws border (2) + title (1) + disclosure (2) + 1 row, which is 6 lines in a 3-line slot.
- Before this change the overrun was 1 line; the disclosure makes it 3.
- Compact mode also applies below 72 columns. The disclosure lines (`evidence-view.tsx:29,72`) aren't `wrap="truncate"`. With about 5 columns of border and padding, line 1 (63 chars) wraps below about 68 columns and line 2 (55 chars) below about 60. Each wrap is a line the budget doesn't count.
- The panels were already off by one: they get `panelHeight - 2` but don't subtract their title line, unlike `worldListHeight` (`ui.tsx:842`). The new test locks that in: `height=12` passes with `<= 15` lines, which is 1 more than the 14-line slot (`evidence-screens.test.tsx:119`).
- **Fix:** subtract title + disclosure from the budget. In compact mode, collapse the disclosure to one short line that still fits (e.g. "Recorded USD, not a bill; $0 may be unreported"). Add a test at about 60×12 that compares against `panelHeight`, not `height+3`.

**2. The TUI and the browser/report show different precision.**
- The TUI's `formatMicroUsd` uses 4 decimals (`evidence.ts:11`). The browser and report use 6 (`comparison.ts:18`, `app.ts:332`).
- So a real recorded cost under $0.00005 shows as `$0.0000` in the TUI, right next to the "Hosted zero can mean unreported cost" line. A small real cost then looks like a missing one, and the numbers won't match when the engineer checks the exported report against the console, which the guide tells them to do.
- **Fix:** use 6 decimals everywhere, sharing one formatter as `COST_DISCLOSURE` already is.

**3. The support-triage pack doesn't show how to start the daemon.**
- `examples/support-triage/README.md:23-28` says to use a fresh data directory, a separate source repo, and to start frozen. It never gives the `hephaestusd --data-dir … --source-repository … --evaluator-executable …` command; that only appears in `docs/CLI.md:24` and `MACOS_INSTALL.md:53`.
- It also doesn't say where `<installed-reference-evaluator>` is after `scripts/install.sh` (presumably `~/.local/bin/`).
- A new engineer can't get from `heph`, which uses the default data directory, to a fresh-directory daemon without piecing this together. Add the command and the evaluator path, or link the exact section.
