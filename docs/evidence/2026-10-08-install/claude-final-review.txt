**Blocker: the run step's harness wait is shorter than the UI's own deadline.**
- In `apps/hephaestus-tui/src/tour-view.tsx:152`, `unfreezeAndRun` polls for up to 20s. Its result lines, including `Ledgered:`, are only rendered once that polling ends (`tour-view.tsx:160-167`). The acknowledgement doesn't show up first.
- In `apps/hephaestus-tui/scripts/pty_tour.py:114`, the harness only waits 15s for `Ledgered:`. Because both lines render at the same moment, the extra 15s `· succeeded` wait at `pty_tour.py:116` adds nothing. The real limit is 15s.
- So if the packaged reference run takes 15–20s, acceptance fails with "tour did not unfreeze and attempt the parent run" even though the UI is still within its deadline. That's plausible on a first launch, with the sandbox and evaluator starting cold.
- **Fix:** give the `Ledgered:` wait about 25s (the UI deadline plus the unfreeze/submit round trips), the same way Arena gets 70s around its 60s.
