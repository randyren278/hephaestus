## Findings

**1. `docs/STATUS.md:52-56` is stale and contradicts the source.** It says "The Forge proposal/assessment workflow cannot yet record a free-form prompt revision." Replace the bullet with:
> - **Automatic Forge changes reference instructions only.** `evolve`, adaptation and Gene extraction choose among 16 deterministic reference operations covering the seven Gauntlet failure families plus casing. Separately, an operator can write a revised prompt for a registered Codex or Claude agent with `genome revise` or the terminal's **Forge: revise a prompt** flow. The proposal records the exact before/after prompt, the hypothesis and the source Selection while keeping the model, authority and World fixed. It is then compared and assessed like any other candidate. Hephaestus does not write prose revisions itself. See [Genomes](GENOMES.md#hosted-prompt-revisions).

**2. `docs/STATUS.md:57-60` is stale.** It still cites only the 2026-09-27 single run and says nothing about the two real hosted comparisons. Replace with:
> - **Real hosted comparisons exist; improvement does not.** On 2026-10-08, two owner-authorized Codex comparisons ran on the public fictional support-triage pack, using 96 experimental calls. One compared the baseline with a checklist prompt. The other compared that checklist with an operator-written Forge revision. Every prompt scored 24/24 and none passed the measured selection gates. The revision's assessment is `metrics_rejected`, and no Champion changed. Codex reported no USD amount. See the [Forge comparison evidence](evidence/2026-10-08-live-forge/README.md). Repository tests still use fake provider CLIs. No hosted-model improvement, measured USD cost, customer acceptance or autonomous hosted-model evolution is established.

**3. Add a "What works" bullet to `docs/STATUS.md` (after line 23).** The list does not mention operator revisions at all:
> - Record an operator-written prompt revision for a hosted agent, bound to its source Selection and hypothesis. Then compare the revised child with its parent and record an evidence-only assessment. A revision never sets itself up for promotion.
