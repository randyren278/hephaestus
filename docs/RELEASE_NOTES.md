Hephaestus runs controlled comparisons of two AI prompt versions on the same
tasks and keeps evidence you can inspect and replay. Install locally on Apple
Silicon or Intel macOS, complete the offline terminal tour, then bring a
workflow with checkable answers. The package includes both consoles and Node.

Operators can record a hosted prompt revision, compare it with its parent,
assess the evidence and download a report. Automatic evolution uses the
deterministic reference-operation catalog. A comparison or Forge assessment
does not by itself authorize Champion promotion.

Hosted work needs your own provider CLI/account and an approved usage allowance.
The two real support-triage comparisons used 96 Codex calls and tied at 24/24;
they establish the workflow, not model improvement, repeatable speed gains,
attributable USD cost or independent customer acceptance. Package acceptance
uses local fixtures and launches no real model.

Verify the downloaded archive's checksum, Sigstore bundle and provenance
before installation. Apple Developer ID signing and notarization are not
implemented. Fresh-user first launch from a quarantined browser download and
provider authentication remain unverified. Git is required; Linux/Windows
packages and Homebrew/crates.io delivery are not provided. Reproducibility
evidence covers ARM64 builds on the same runner setup, not Intel or independent
third-party rebuilding. An assisted paid pilot remains a proposed service.
