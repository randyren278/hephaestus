## Progress since baseline

- The domain vocabulary and lifecycle are executable, versioned, and fail closed.
- The canonical SQLite event ledger and BLAKE3 artifact store persist and verify real on-disk state.
- Strict Genome and World compilers normalize JSON/YAML, resolve ancestry and artifacts, constrain authority, enforce exact World comparability, and retain the normalized authorized mutation scope for future Forge enforcement.
- The runnable daemon and CLI enforce a single writer, owner-only authenticated IPC, persistent operator freeze/kill state, Genome inspection, and verified replay.
- The offline reference runtime exercises isolated worktrees, lifecycle operations, expiring capability tokens, and hard output/authority failure paths. A provider-neutral local process supervisor independently enforces allowlisted environments, stdin prompts, process-group interrupt, and hard wall/output limits. macOS hosted commands are wrapped in a live-tested deny-by-default Seatbelt policy; unsupported hosts fail closed. Hosted provider invocations are built but not executed without a billable permit.
- The Experience Plane records the full observable trace vocabulary as bounded redacted CAS artifacts with safe ledger receipts. `RecordedRuntime` binds real adapter lifecycle, checkpoints, failures, provider-visible events, latency, and known deterministic cost to immutable run/Genome/World provenance, failing closed when required start or resume evidence cannot persist. Structured observations, hypotheses, evidence, and contradictions require verified source events and exact provenance; every lesson remains explicitly unverified and cannot become a Gene here. A trusted, non-caller-constructible Experience capability now rehydrates redacted fields from canonical receipt and CAS bytes, recursively validates earlier source events and evidence artifacts, and binds the result to the exact verified event hash after restart.
- The runtime trust checkpoint requires every supervised external launch to traverse the detected OS isolation policy, records adapter-owned completion reasons and elapsed time, reserves terminal evidence capacity, and retains failed containment and unpersisted observations for retry. The current gate holds a 95% per-module floor across 31 production-critical modules and uses branch coverage only for modules with branch records, falling back to lines otherwise. The mutation ratchet includes Arena selection, daemon history verification, and Python histogram invariants in this change.
- The production daemon now composes the registered World/Genome, read-only deterministic runtime, sandbox, evidence wrapper, ledger, and CAS behind `hephaestus run <genome-id>` and the typed `hephaestus evaluate` path. Real daemon/CLI tests verify freeze and budget gating, runtime-owned task/input/seed/environment/budget provenance, signed-result replay, anchored verifier continuity before the first result, exact authenticated Arena consumption after restart, output and trace artifact hashes, sandbox cleanup, terminal projection, and replay after restart.
- The measurement-only Arena now accepts task plans made solely of daemon-signed runtime-result event IDs, resolves their Genome/World/source/output provenance from verified history, enforces exact World-committed task input plus seed/environment/budget pairing, re-hashes and launches the World-bound evaluator in a separate offline bounded worker, validates its canonical request-bound aggregate response, exposes a visible-only summary without the sealed operator event hash, and records deterministic idempotent evaluator receipts. World-bound manifest bytes rehydrate only through strict schema, constructor, visibility, and byte-exact canonical checks; an operator-only scheduling view exposes visible or sealed task IDs and inputs without expected outputs. The daemon now loads the complete task sets itself, pins one revision, launches parent and candidate trials through separate supervised offline processes and private worktrees, validates the evaluator before spending candidate work, cleans all private roots, and makes identical retries reuse authenticated events. Arena retains authenticated terminal failures as unreliable and incorrect rather than discarding them, aggregates correctness, reliability, cost, and latency without overflow, commits each run event hash into evaluator-owned evidence, and mints operator-only aggregate selection evidence bound to the exact evaluation event hash. That evidence rehydrates byte-identically from verified history after restart without exposing task identities, task order, expectations, outputs, trace addresses, or raw store access. `arena select <evaluation-id>` now recomputes the fixed-seed histogram bootstrap and measured Pareto/effect/cost gates from that trusted capability and the exact compiled World, then writes a canonical BLAKE3-addressed receipt referenced by a deterministic event. Exact retries and history verification compare the recomputed receipt bytes and complete canonical event. The receipt names correctness losses separately from invariant regressions; because no trusted invariant checker exists yet, it explicitly records the invariant gate as unverified and never marks promotion eligible. The Python histogram analysis matches Rust's canonical order and floor rounding and rejects unsupported confidence 10000 and bootstrap work over 20 million draws. Forge, lineage, invariant authorization, promotion, and rollback remain pending.
- The mutation runner now gives each suite an isolated process group, escalates and verifies descendant termination on timeout or interruption before restoring source, bounds final pipe draining, honors explicit command overrides, and reports every effective command and timeout. Deterministic tests cover silent grandchildren, escaped pipe holders, interruption, and byte-exact restoration.
- Hosted mutation CI splits the runtime controls by source module, preserving the exact 41-target ratchet while preventing one long serial shard from exhausting a runner.
- Genome and World registration now replays through one trusted projection, `RegisteredObjects`, instead of ad-hoc maps in the control server: acyclicity is enforced by replay order (a parent must already be registered under the same World), payloads must round-trip to exact canonical JSON, artifacts must be byte-exact compiler output, and any violation fails daemon startup. The same projection backs live operator registration: `hephaestus arena manifest`, `artifact put`, `verifier`, `world register|list|show`, and `genome register|list|show` make the product usable end to end without touching the ledger by hand. A real-binary CLI test and `scripts/quickstart.sh` drive the full loop (register, run, paired Arena evaluation, replay, crash, recovery); the manifest now declares 276 mutations across 31 production-critical modules.
- If the scorer thread cannot launch after all paired trials have been signed and persisted, the daemon appends an interrupted Arena terminal and releases the active slot only after that append succeeds. The job has no evaluation receipt; if terminal persistence fails, the daemon returns an error and leaves the active scoring projection intact for recovery.
- The Ink operator console now provides live status, freeze and cancellation controls, and Arena progress by known evaluation ID through the daemon API. An arm64 macOS archive has passed an isolated-home install and offline Arena acceptance with bundled Node and a Git prerequisite. The package has not been accepted on Intel macOS or a host without Git; the TUI does not yet expose the complete lineage, receipt, and authoring workflow required by roadmap item 9.

## Remaining product loop

There is currently no active hosted-provider adapter, provider-native tool/context/memory event parser, mutation engine, lineage, invariant authorization, promotion/rollback, validated Gene Bank, drift response, canary deployment, web console, public benchmark, or autonomous evolution loop. The current Ink TUI is a partial operator console. The deterministic reference run and protected paired Arena plus its non-authorizing measured-selection receipt are trust-substrate tracer bullets, not a hosted-model or autonomous-improvement claim.

The repository is therefore a runnable local trust substrate with one real non-billable execution path, not yet the evolutionary product described by the full plan. Later application layers remain unclaimed until their own product-path evidence exists.

## Audit conclusion

Keep every existing implementation feature. The immediate priority is a trustworthy local Arena and evaluator boundary, followed by one complete local evolution loop before population intelligence, distributed execution, or web surfaces.
